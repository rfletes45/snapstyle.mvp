### Scorecard Transport Contract

Scorecards do **not** add a new `MessageKind`. They currently travel through chat as a trusted text envelope:

```typescript
kind: "text"
text: "[SCORECARD_V1]{json}\nGame Scorecard"
clientId: "server" | `server-share:${uid}`
```

Important rules:

- the raw `text` field is not the trust source; `clientId` is
- `getTrustedScorecardPayload()` only returns data for trusted `clientId` values
- `isScorecardMessage()` is intentionally broader and treats sentinel-prefixed text as a scorecard for sanitization, even before trust verification
- SQLite persists `clientId` via the `client_id` column so server-authored scorecards stay trusted after local hydration
- plain user-authored sentinel text is rejected by `sendMessageV2`
